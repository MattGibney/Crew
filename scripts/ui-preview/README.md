# Local Crew design preview

Run `node scripts/ui-preview/start.mjs` after `npm ci --ignore-scripts`. Open http://127.0.0.1:4451 in the Codex built-in browser. The scenario selector and Reset scenario control sit above the actual Crew UI. Use the browser's native Annotate/Adjust controls and send comments to this chat.

The preview runs Vite with React hot refresh plus the existing synthetic browser fixture on loopback ports 4451/4452. Set `CREW_PREVIEW_PORT` to choose another adjacent pair. Ctrl-C stops both processes. Keep the terminal session alive during design iteration. Edits to the real manager components, shared UI and canonical theme are reflected directly in the preview and carry into product builds.

Scenarios cover mixed typed/spoken messages, empty state, concurrent/queued workers, paused/failed/completed history, questions and a native approval form. Worker Conversation, Work notes and Links contain fictional evidence. Normal project navigation, project management, Settings saves/lifecycle controls and call controls are usable. Voice is configured in Settings → Manager profile; the composer has only call/mute controls and no microphone mode selector. Project and scenario changes remount the app and release synthetic voice; Reset restores the fixture conversation, task state and prompt settings. Drafts belong to this local browser origin; manager voice is a per-project profile preference in the synthetic backend. Project registry edits last for the page lifetime. A full reload restores the fictional registry.

All data is fictional; DEMO references are not real tickets. The fixture imports no real controller, auth, worker, updater or project runtime. Native workspace actions are replaced with an in-memory bridge. The existing browser-media fixture replaces microphone acquisition, WebRTC and AudioContext before React runs; media playback is stubbed, and external links are blocked. Connect/Mute/End exercise genuine UI state transitions using fake tracks and peers. Update requests return unsupported and never download/install. There is no model generating responses: typed submissions get a clearly identified fixture echo and manager-mediated worker requests get fixture acknowledgement, not real execution. Timing/liveness is synthetic and naturally expires unless the scenario is reset.

Manager-mediated worker lifecycle actions update only the fictional task status. Question review adds a fictional question to the manager conversation. The HTTP preview additionally denies microphone/camera through Permissions-Policy and blocks remote connections through Content-Security-Policy.

Production `vite build` uses `renderer/src/manager/main.jsx`; it does not load the preview entry or controls. No installed Crew app, user profile/configuration/history, acceptance evidence or external business system is involved.
