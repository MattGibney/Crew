# AI-010: Automatic project setup

Status: Implemented and validated through source, browser and historical installed setup checks.

## Delivered capability

Folder selection and bounded analysis save a canonical repository path, sensible project context, an existing starting branch and proven Linear choices. Users choose recognizable names; opaque identifiers remain internal. Branch and Linear selections save directly, while unavailable connections can be deferred.

## Validation and limits

Checks exercised choose/analyze/save, cancellation, canonical-path/name sanitization, real connected-tool name discovery, saved values and reopening. No project scripts, worker, microphone or external ticket mutation starts during setup. Public records omit private workspace names, identifiers and customer mappings.

Private run identities, workspace links, machine paths and project-specific operational evidence are intentionally excluded from this public record. Historical capability evidence is not a claim of current device, account or production readiness.
