# AI-008: Guided setup and project discovery

Status: Implemented; automatic reversible configuration was refined in AI-010.

## Delivered capability

Added reopenable setup for local tools, ChatGPT sign-in, project fields, file access, optional microphone permission and readiness. Discovery uses one cancelable subscription-backed setup job over a bounded sanitized source snapshot, with no project scripts or business worker.

## Validation and limits

Checks distinguish configured, verified, unavailable, denied and unknown. Stale configuration/prompt results are rejected; active tasks, manager work and voice guard guided apply. Setup never asks for API keys or starts capture/work automatically.

Private run identities, workspace links, machine paths and project-specific operational evidence are intentionally excluded from this public record. Historical capability evidence is not a claim of current device, account or production readiness.
