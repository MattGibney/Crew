# AI-016 — Open microphone by default and retain input across app switching

Status: In progress.

User-authorized scope: open microphone is the default. Explicit Connect starts the call and requests/enables microphone once connected. Established open-mic input continues through ordinary window blur, hiding or app switching until explicit mute/disconnect. Push-to-talk remains optional and stops on release/blur. Explicit mute survives reconnect/error paths. Window close/disconnect/quit still releases media. No worker, speech or backend behavior changes.

Root cause: useVoiceSession initialized push-to-talk, deliberately connected a silent transport only, and unconditionally called stopInput on window blur/hidden. These were previous requirements, now superseded by the user's direct feedback.

Implementation: auto-start input once per connected call under the selected mode and persistent mute intent. Capture tracks retain existing generation/serialized replacement cancellation. Only PTT responds to focus loss. Mute/cancel invalidates pending capture synchronously and persists its intent independently of transport teardown. UI explains auto capture and background behavior, with Mute/Unmute/Retry/Cancel actions.

Acceptance uses synthetic microphone, WebRTC, API and audio graph fixtures; do not capture physical microphone during the user's other voice call. Verify default/single Connect, blur/hidden retention, explicit mute across reconnect/error, permission denial/retry/cancel, late stream cleanup, complete disconnect/page close cleanup and PTT release/blur. Physical acoustic/device behavior remains a coordinated human check. Publish the signed patch after checks through the established deliberate release pipeline.

Local acceptance: 210/210 tests passed, including ten new tests invoking the actual hook with synthetic browser primitives. A browser running the built React UI passed one-click capture, open-mic blur/hidden retention with no duplicate acquisition, explicit mute/reconnect, denied permission/explicit retry, cancellation and late grant disposal, pagehide cleanup, PTT connect-without-capture/held-key release and final disconnect cleanup.
