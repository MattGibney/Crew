# GitHub #14 — Worker overview and detail

Issue: https://github.com/MattGibney/Crew/issues/14

## Agreed scope

Many small cards with ticket/task identity, labelled status and title in the main manager view. A separate full worker overview adds latest progress and verified execution elapsed time. Selecting a card opens full main-area read-only Conversation, Work notes and Links tabs. All directions and lifecycle requests continue through the manager. No direct worker conversation or duplicate approval protocol.

A persistent thin manager call bar appears on other project views; Settings shows none while preserving the call in the background. Playback and transport outlive view changes. View navigation releases PTT without changing established open-mic intent. Existing project-switch, close and quit behavior remains authoritative.
