Pending/failed teardown stays visible and actionable; successful teardown removes ordinary cards/counts/attention and preserves historical assignment, result, conversation and evidence. Latest user correction: Project Settings provides a simple project-scoped table ordered newest known archive time first, one row per worker with Restore and Delete permanently actions only. No archive detail/editor. Legacy removed/disposed records are included with unknown time labelled honestly. Open detail completion returns to manager with call/draft continuity. Completed/stopped/paused workers remain retained until explicitly archived.

Restore semantics await explicit user clarification about safe environment reconstruction versus history then manager recovery. No new cleanup engine, merge, release or version bump. #42 continuation and #37 TypeScript migration are separate unmerged changes requiring integration validation.
