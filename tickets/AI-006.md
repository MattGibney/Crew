# AI-006: Reusable local project instances

Status: Implemented and locally validated.

## Delivered capability

One configured project per local JSON/Markdown instance, with separate state, port, backing conversation and editable manager/worker instructions. Repository workers use configured committed refs and scoped ticket evidence; fixture mode remains available for disposable acceptance.

## Validation and limits

Configuration, packaging boundaries, task identity, worktree isolation, sandbox refusal and actual subscription worker question/resume behavior were exercised. No automatic backlog, project switcher, hosted infrastructure or credential transfer was added. Destination-machine tools, permissions and project mapping still require local validation.

Private run identities, workspace links, machine paths and project-specific operational evidence are intentionally excluded from this public record. Historical capability evidence is not a claim of current device, account or production readiness.
