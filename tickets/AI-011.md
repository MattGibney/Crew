## Implemented contract

The one-active-task restriction is removed. Independent ticket-scoped tasks can execute concurrently up to configured capacity, each with a genuine Git worktree and separate Codex session. Manager-only lifecycle requests are durable and idempotent by action ID, correlated with the expected run and serialized per worker. Worker MCP access remains report-only and bound to its own task/run. Answers require the exact current question and cannot spill into another worker.

Controller restart adopts surviving execution without duplicate launch. Stop/pause preserve task records and worktree contents; resume continues the same worker conversation/worktree in a new run. Disposal retains records and refuses unsafe/dirty environments. Actual process liveness, timestamps and confirmed exits are distinct from requested actions. Hook bootstrap/start/readiness/resume/cleanup commands have bounded durable supervisors and unique worker environment identity; hook evidence is not proof of a functioning Set1 application runtime.
