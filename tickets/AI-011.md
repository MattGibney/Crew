# AI-011: Concurrent workers and correlated lifecycle

Status: Implemented; actual disposable multiworker lifecycle acceptance completed.

## Delivered capability

Independent worktrees and subscription Codex sessions support concurrent explicitly agreed tasks. Durable task/run/action-correlated stop, pause, resume, start and disposal are idempotent. Questions yield execution capacity; answers resume only the matching original conversation and worktree.

## Validation and limits

Actual checks covered overlapping workers, controller recovery, targeted stop, same-session resume, questions/results and disposal with retained evidence. A real separately grouped child-process leak was reproduced and corrected using verified PID/start/command identities. Dirty work or uncertain ownership blocks removal. Fixture hooks alone do not establish readiness of an arbitrary application.

Private run identities, workspace links, machine paths and project-specific operational evidence are intentionally excluded from this public record. Historical capability evidence is not a claim of current device, account or production readiness.
