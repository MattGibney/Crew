# React renderer foundation (AI-013)

Crew's manager and native setup are React JavaScript entry points built by Vite. Both use genuine shadcn/ui `base-nova` components generated by the official shadcn 4.22.1 CLI (`tsx: false`, CSS variables, neutral base), Base UI primitives and Lucide React icons. Generated component files live in `renderer/src/components/ui`. No runtime CDN, API key or theme service is required.

## Change the theme in one place

**Edit only `renderer/src/styles/theme.css`.** This is the canonical global stylesheet for both entry points and is the `tailwind.css` path in `components.json`.

Copy CSS from the [official shadcn theme builder](https://ui.shadcn.com/create) or [official theme scaffold](https://ui.shadcn.com/docs/theming):

- If the copy contains `:root` and `.dark` token blocks, replace those blocks in this file directly. Leave its standard imports and `@theme inline` mapping in place.
- If the copy includes the complete global CSS (imports, `@theme inline`, token blocks and base layer), replace the file directly with that complete output.

There is no Crew palette translation, second token map, JavaScript color table or per-component primary override to update. Standard CSS colors such as `oklch(...)` and hex both work. Keep the Tailwind 4 `@import "tailwindcss"` and current `@import "shadcn/tailwind.css"` when using the complete current scaffold. Components reference the official semantic utilities (`bg-primary`, `text-muted-foreground`, `border-border`, etc.). The initial primary `#0c58fc` is the most common blue sampled from the approved Four bold shapes icon. Neutral surfaces use the official scaffold.

Crew currently opens in light mode. No theme provider, theme selector, `.dark` class or operating-system theme listener is installed. The optional `.dark` block is inert and retained for direct official CSS paste compatibility.

After pasting, run `npm run renderer:build`, then rebuild/relaunch the app. A running release does not hot-reload CSS. Do not edit generated `renderer-dist` output.

## Build and security

Run `npm ci`, then `npm run renderer:build`. `npm run desktop:dev` and `npm run desktop:build:mac` build the renderer first. Source-only controller launches require a prior renderer build. The packaged app includes compiled static assets; React, Vite and Tailwind do not run a development server inside the app.

The manager uses the existing loopback API and one SSE consumer. Its renderer has no Node or preload access. Setup uses only the existing bounded `window.crewSetup` API and an exact trusted compiled file URL, with context isolation/sandbox and blocked navigation. Compiled scripts and styles are local; browser origins and API request checks remain enforced.
