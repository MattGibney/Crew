Permissions and local access

Microphone

Only voice needs microphone access. Request it now, or leave it for your first call. This button asks macOS for permission without recording or starting voice.

Project files

Check the configured folders, starting branches, prompt files and a temporary write in this instance’s state folder. macOS may prompt for a protected folder. Terminal access does not establish packaged-app access. Worker sandbox access still needs a bounded task.

Local network

Crew’s window talks to its controller at 127.0.0.1; voice uses WebRTC and online Codex services. No LAN discovery feature is required. macOS does not offer Crew a universal Local Network request/check here. If macOS asks during an actual operation, review it then. A blocked operation is not automatically a Local Network denial.

Crew does not need camera, screen recording or Full Disk Access for this setup.
