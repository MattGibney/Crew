# Service brand assets

Service logos identify connected providers, alongside their visible names.

- GitHub, Gmail and Linear: SVG paths from the `simple-icons` package, with upstream source attribution in its icon metadata.
- Slack: official symbol from https://a.slack-edge.com/9cc0056/img/icons/favicon-32.png, linked by https://slack.com/media-kit.

Render through `ServiceLogo`. Keep assets bundled locally and use the generic plug fallback for unknown services. Brand marks belong to their respective owners.
